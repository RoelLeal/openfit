# Contributing

Thanks for helping! This page gets you from clone to pull request.

## Principles (please read before proposing features)

1. **Local-first.** IndexedDB on the device is the source of truth. Nothing
   requires a server, and no personal data leaves the device.
2. **Small and fast.** No runtime dependencies. The first load has a size budget
   (`npm run size`) that CI enforces. Ask before adding a package: what does it
   replace, how big is it, is it maintained?
3. **Simple.** Prefer a plain function over an abstraction. Add extension points
   only when they have a use today.
4. **Accessible and bilingual.** Real labels, keyboard navigation, both
   `src/i18n/en.ts` and `src/i18n/es.ts` updated together (a test checks it).

## Setup

```bash
npm install
npm run dev
```

Node 22.18+ (see `.nvmrc`). Scripts under `scripts/` run TypeScript directly with
Node, no build step.

## Before you open a pull request

```bash
npm run ci          # lint, types, tests, build, size budget
npm run e2e         # optional: browser smoke test (needs Chrome installed)
```

`npm run format` fixes formatting.

## Where things go

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). In short:

- `src/core` — pure logic (units, nutrition, dates, backup format). Tests next
  to the code. Never touches the DOM or IndexedDB.
- `src/db` — IndexedDB wrapper, schema, migrations and repositories. The **only**
  code that reads or writes the database.
- `src/screens`, `src/components` — Svelte 5 UI.
- `src/platform` — browser vs. native (Capacitor) differences.
- `scripts` — data pipeline and build helpers.

## Changing the database

1. Append a new migration in `src/db/schema.ts`. Never edit a released one.
2. Bump `SCHEMA_VERSION` in `src/core/backup.ts` and add a `BACKUP_MIGRATIONS`
   entry so old backup files still restore.
3. Add a test in `src/db/idb.test.ts` with data created by the previous version.

## Food data

Fixes to the built-in catalog go in `data/base-foods.csv` (with a public,
reusable source for the values), then `npm run catalog`. See
[docs/DATA.md](docs/DATA.md).

## Adding a language

Copy `src/i18n/es.ts`, translate every key, register the loader in
`src/i18n/index.svelte.ts` and the locale in `src/core/types.ts`. The i18n test
checks that keys and placeholders match `en.ts`.

## Mobile

The Android and iOS projects live in `android/` and `ios/` and are generated by
Capacitor from the same web code. Most changes need no native work; when they
do, see [docs/MOBILE.md](docs/MOBILE.md).

## Pull requests

Keep them focused. Describe what and why, and how to test. A maintainer will
review; CI must be green. By contributing you agree that your contribution is
licensed under the MIT license (code) and CC0 (food data).
